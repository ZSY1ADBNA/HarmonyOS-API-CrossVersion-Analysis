# 专用语义适配与独立检索

日期：2026-10-12。继续第二批版式试点，本批把部分原文片段进一步整理为可检索的文档候选，验证归属和重载；没有把它们当成已确认的SDK公开API。

## 实际处理范围

五个正式发行各执行四种专用适配：AudioRenderer、AudioCapturer、Button构造接口/fontSize、OH_AVErrCode。共20次适配、17份不同原文；旧发行音频文档包含多个接口，因此同一文件分别按两类接口处理，不重复计为两份文档。

早期C错误码文件是native__averrors_8h.md的Doxygen版式，较新版本是capi-native-averrors-h.md的CAPI版式。本批分别处理内联br分隔枚举与独立枚举表，保留原始赋值，不用新版IPC页补旧发行。前一批IPC代表页三项缺口仍成立，本批补充的是各版本真实存在的AVCodec C错误码样本。

形成1269条带证据的候选记录：588条接口方法、552条参数、105条枚举成员、10条接口属性、10条组件构造接口、4条组件调用式属性。它们按发行分别保存，参数和枚举成员也单独计数，因此不是1269个独立公开API。

原件SHA256与账本一致，每条记录保留固定提交、路径、Git blob、行号和原文；方法签名与原始声明行逐项一致，上下文片段与原文范围一致。C枚举名称集合与原文全部赋值名称一致。本批不依赖本地未发布通用解析器，也没有覆盖其代码。

## 防止误归属和字段污染

- AudioRenderer与AudioCapturer均有state，分别绑定到真实接口标题，不合并同名属性。
- callback/Promise重载保持各自声明位置与签名。参数表只能产生参数，必须指向对应可调用声明；若同一栏目有多个签名共用表格，标记绑定歧义，不猜分配。
- Button构造接口、fontSize调用式属性和音频接口方法使用不同类别；示例调用本身不会生成声明。4.1仍没有独立fontSize标题，因此没有补造该属性条目。
- 返回值表作为方法字段保存，不当参数或属性。声明签名保持原文，尚未做完整类型AST解析。
- 从当前声明栏目读取权限/系统能力/版本等明确标签；参数说明中的版本信息不会覆盖方法版本。C枚举行内版本与父级元信息分别保存，不静默继承到成员。没有明确证据的字段留空。

Kit、模块、SDK公开范围和正式API身份的全量关联仍未完成；本批也没有验证所有音频标题/类的语义覆盖、全部重载和所有文档类型。方法记录是文档候选，不是CALLS调用边或编译结果。

## 独立数据库和验证

数据库位于忽略的data/delivery/structured/yu-semantic-pilot/candidate-search.db；候选正文与只读查询证据在同目录。每次在专用目录建立独立文件，完成检查并关闭连接后替换本批自己的数据库文件，不接触共享RAG、Neo4j或网站。检查失败则退出并单独保留失败文件，不覆盖上一次通过检查的库及候选正文。曾发现SQLite事务上下文没有关闭连接导致Windows文件占用，已修正为显式关闭后再发布。

40项实际批次检查通过，包括两次导入条数不变、主键无碰撞、原文位置一致、参数归属、两个state的分别检索、五发行setVolume重载保留、发行筛选、未知发行空结果，以及FTS外部内容完整性检查。FTS按rowid触发更新，不逐条全表扫描删除。

新增11项解析/索引回归与1项查询回归通过；包含真实失败管线保留旧库及旧正文的测试。只读连接实际尝试DELETE被拒绝，查询条数限定1至100，返回默认省略大段原文但保留来源。真实6.1数据库查询分别返回一条AudioRenderer.state与AudioCapturer.state，来源文件不同，各自标记sdk_public_status=not_verified。

FTS与查询入口目前验证的是英文技术标识符和精确名字/接口过滤；未确认中文自然语言检索效果。未知发行的空结果只表示本批没有匹配，不表示官方不存在相应API。
